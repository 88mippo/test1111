## 🆘 Troubleshooting

### 🔴 Installation Issues

#### ❌ "Installation Failed" or "Installation failed"
**Solution:**
- ✅ Run `setup.exe` **as administrator** (right-click → "Run as administrator")
- ✅ **Disable antivirus** temporarily (Windows Defender, Kaspersky, Avast, etc.)
- ✅ **Reinstall** Visual C++ 2022 Redistributable (download from Microsoft)
- ✅ **Clean** `%LocalAppData%\Temp` folder
- ✅ Download file **again** (may be corrupted)
- ✅ Restart computer and try again

#### ❌ "Archive won't extract" or "Wrong password"
**Solution:**
- ✅ **Check password:** must be `github` (case-sensitive!)
- ✅ Use **7-Zip** or **WinRAR** (not Windows built-in)
- ✅ Download file **again** if corrupted
- ✅ **Verify** file downloaded completely (check size)

#### ❌ "Not enough disk space"
**Solution:**
- ✅ Need **2GB free space** minimum
- ✅ Clean C: drive from unnecessary files
- ✅ Delete temp files: `%LocalAppData%\Temp`
- ✅ Use Disk Cleanup utility

### 🟡 Application Issues

#### ❌ "App won't start" or "Crash on startup"
**Solution:**
- ✅ **Restart computer** (often helps!)
- ✅ **Reinstall** Visual C++ 2022 Redistributable
- ✅ **Reinstall** app completely
- ✅ Clean folder: `%LocalAppData%\TradeDeck\`
- ✅ Check **Windows Defender** isn't blocking it
- ✅ Try running as administrator

#### ❌ "Indicators not showing" or "Indicators loading"
**Solution:**
- ✅ **Restart** app completely
- ✅ **Check internet** connection (required for data loading)
- ✅ Clean **app cache:** delete `%LocalAppData%\TradeDeck\Cache`
- ✅ **Update** to latest version
- ✅ Restart computer

#### ❌ "High CPU/Memory Usage" or "Program is slow"
**Solution:**
- ✅ **Close unnecessary apps** (Chrome, Spotify, etc.)
- ✅ **Reduce** number of open charts (max 50-100)
- ✅ **Disable** non-critical indicators
- ✅ **Update** to latest build
- ✅ **Increase RAM** (if using >90%)
- ✅ Check **Windows updates**

#### ❌ "No data" or "Connection error"
**Solution:**
- ✅ **Check internet** connection
- ✅ **Restart router**
- ✅ **Add TradeDeck** to Windows Firewall exceptions
- ✅ Try **different data server** in settings
- ✅ **Restart app**
